Политика обработки персональных данных

1. Общие положения

Настоящая Политика обработки персональных данных составлена в соответствии с требованиями Федерального закона РФ от 27.07.2006 №152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных и меры по обеспечению их безопасности.

Оператором персональных данных является владелец сайта, расположенного по адресу http://le5h.ru/ (далее — Оператор).

2. Персональные данные, обрабатываемые Оператором

Оператор может обрабатывать следующие персональные данные, передаваемые пользователем через формы на сайте:
— имя;
— номер телефона;
— адрес электронной почты;
— иные данные, переданные пользователем добровольно.

3. Цели обработки персональных данных

Персональные данные обрабатываются исключительно в следующих целях:
— обратная связь с пользователем;
— обработка запросов и сообщений пользователя;
— предоставление информации по запросу пользователя.

Персональные данные не используются для иных целей.

4. Правовые основания обработки персональных данных

Оператор обрабатывает персональные данные на основании добровольного согласия пользователя, выраженного путем передачи данных через формы сайта.

5. Условия обработки персональных данных

— Персональные данные не аккумулируются в целях массового хранения.
— Персональные данные не передаются третьим лицам, за исключением случаев, предусмотренных законодательством РФ.
— Данные, передаваемые сторонним сервисам, используемым сайтом (хостинг, почтовые сервисы и т.п.), обрабатываются в соответствии с политиками обработки персональных данных соответствующих сервисов.

6. Сроки обработки персональных данных

Персональные данные обрабатываются до достижения целей обработки либо до момента отзыва согласия субъектом персональных данных.

7. Права субъекта персональных данных

Пользователь имеет право:
— получать информацию о факте обработки его персональных данных;
— требовать уточнения, блокирования или уничтожения своих персональных данных;
— отозвать согласие на обработку персональных данных путем направления запроса Оператору.

8. Меры по защите персональных данных

Оператор принимает необходимые организационные и технические меры для защиты персональных данных от неправомерного доступа, утраты, изменения или распространения.

9. Заключительные положения

Передавая свои персональные данные через сайт, пользователь подтверждает ознакомление с настоящей Политикой и выражает согласие на обработку персональных данных в соответствии с её условиями.
